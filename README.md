# utushiyo — 投げ込み・整理アプリ

頭に浮かんだことをスマートフォンから素早く一か所に投げ込み、あとで整理・実行するための Web アプリです。
要件は [requirements.md](requirements.md) にまとめています。

- 起動したら通信を待たずに、端末内のデータをすぐ表示します
- 電波がなくても、起動・閲覧・入力・編集ができます
- アクセストークンを設定しなくても、端末内保存だけで全機能が使えます
- アクセストークンを設定すると、**非公開の** データ用リポジトリの `items.json` と同期します

このリポジトリにはアプリ本体だけが入っています。データやアクセストークンは含まれません(含めないでください)。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(画面・保存・同期のすべて) |
| `sw.js` | Service Worker(アプリ本体を端末にキャッシュし、オフラインで起動できるようにする) |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコン |
| `icons/` | アイコン画像 |
| `.nojekyll` | GitHub Pages でファイルをそのまま公開するための目印 |
| `templates/data-repo/CLAUDE.md` | データ用リポジトリに置く `CLAUDE.md` のひな形 |

## 使い方(画面)

- **ホーム**: 投げ込み欄、インボックスの件数、1件表示、今日やる の一覧
- **1件表示**: 「今日やる」→「やること」の順に1件ずつ表示します。「完了」で完了、「後回し」で順番の最後へ回します
- **メニュー(左上の ☰)**: リスト別の一覧、ためておくリスト(本・映画など)、完了済み、設定
- 項目をタップすると、編集・完了・削除ができます
- 右上の小さな表示が同期の状態です(端末内のみ / 同期済み / 未送信 n / エラー)。タップすると設定画面が開きます
- `アプリのURL?add=テキスト` を開くと、そのテキストがインボックスに保存されます

## GitHub Pages の有効化手順

アプリを `https://(ユーザー名).github.io/utushiyo/` で公開するための手順です。最初に一度だけ行います。

1. パソコンかスマホのブラウザで、このリポジトリ(`https://github.com/hifumijus/utushiyo`)を開きます
2. 公開したい内容が `main` ブランチに入っていることを確認します(作業用ブランチにある場合は、プルリクエストを作って `main` に取り込みます)
3. リポジトリの上部にある **Settings**(歯車のマーク)を押します
   - スマホで表示されないときは、画面を横にスクロールするか、「…」の中を探してください
4. 左側のメニューから **Pages** を選びます
5. **Build and deployment** の **Source** で **Deploy from a branch** を選びます
6. その下の **Branch** で `main` を選び、右側のフォルダは `/ (root)` のままにして **Save** を押します
7. 1〜3分ほど待ってから Pages の画面を開き直すと、上部に **Your site is live at …** と公開先の URL が表示されます
8. その URL を開き、アプリが表示されれば完了です

> 注意: GitHub Pages で公開されたページは誰でも見られます。ただし、公開されるのはアプリ本体だけで、あなたのデータは各端末と非公開のデータ用リポジトリにしか保存されません。

### iPhone のホーム画面に追加する

1. iPhone の **Safari** で公開先の URL を開きます
2. 画面下の共有ボタン(四角から上向き矢印が出ているマーク)を押します
3. **ホーム画面に追加** を選び、右上の **追加** を押します
4. 以後は、ホーム画面のアイコンから起動します。一度開いておけば、電波がなくても起動できます

> **重要**: iPhone では、Safari で開いたときと、ホーム画面のアイコンから開いたときで、**端末内の保存場所が別々** になります。トークンの設定や入力したデータは共有されません。普段はホーム画面のアイコンから使い、同期の設定もホーム画面のアイコンから開いた画面で行ってください。

### アプリを更新したとき

`index.html` などを変更して公開し直したときは、`sw.js` の先頭にある `CACHE_VERSION`(例: `'v1'`)を `'v2'` のように変えてください。各端末では、次に起動したときに裏で新しい版を取得し、その次の起動から新しい版になります。

## アクセストークンの作り方と設定方法

GitHub との同期を使う場合の手順です。使わない場合は、この章は飛ばしてかまいません(端末内だけで全機能が使えます)。

アクセストークンは「アプリがあなたの代わりに GitHub を読み書きするための合い鍵」です。
**データ用リポジトリだけを読み書きできる権限** に絞って作ります。

### 手順1: データ用の非公開リポジトリを作る

1. GitHub の右上の **+** から **New repository** を選びます
2. **Repository name** に名前を入れます(例: `utushiyo-data`)
3. 公開範囲は必ず **Private**(非公開)を選びます
4. **Add a README file** にチェックを入れます(空のリポジトリだと同期できないため)
5. **Create repository** を押します
6. 作ったリポジトリに、このリポジトリの `templates/data-repo/CLAUDE.md` の内容を `CLAUDE.md` という名前で追加しておくと、Claude Code に振り分けを頼むときのルールになります
   - リポジトリの画面で **Add file** → **Create new file** を選び、ファイル名に `CLAUDE.md` と入れて内容を貼り付け、**Commit changes** を押します

`items.json` は作らなくてかまいません。最初の同期のときにアプリが作ります。

### 手順2: アクセストークンを作る

GitHub の「Fine-grained personal access token(きめ細かい権限のトークン)」を使います。

1. GitHub の右上の自分のアイコンを押し、**Settings** を開きます
   (リポジトリの Settings ではなく、自分のアカウントの Settings です)
2. 左側のメニューのいちばん下にある **Developer settings** を押します
3. **Personal access tokens** → **Fine-grained tokens** を選びます
4. **Generate new token** を押します
5. 次のように入力します
   - **Token name**: 分かりやすい名前(例: `utushiyo iPhone`)。端末ごとに作ると、紛失時にその端末の分だけ無効にできます
   - **Expiration**: 有効期限。期限が切れると同期がエラーになるので、そのときは作り直して設定し直します
   - **Resource owner**: 自分のアカウント
   - **Repository access**: **Only select repositories** を選び、手順1で作ったデータ用リポジトリ **だけ** を選びます
   - **Permissions** → **Repository permissions** の **Contents** を **Read and write** にします
     (**Metadata** は自動で **Read-only** になります。ほかの権限は追加しません)
6. いちばん下の **Generate token** を押します
7. `github_pat_` で始まる文字列が表示されるので、コピーします
   - **この画面を閉じると二度と表示されません。** すぐに次の手順で入力してください
   - トークンをメモ帳やチャット、このリポジトリなどに保存しないでください

### 手順3: アプリに設定する

1. アプリを開き(iPhone ではホーム画面のアイコンから)、右上の同期表示か、☰ → **設定・同期** を開きます
2. 次のように入力します
   - **データ用リポジトリの持ち主**: 自分の GitHub ユーザー名(例: `hifumijus`)
   - **データ用リポジトリの名前**: 手順1で作った名前(例: `utushiyo-data`)
   - **ブランチ**: `main`(変えていなければそのまま)
   - **ファイル名**: `items.json`(そのまま)
   - **アクセストークン**: 手順2でコピーした文字列
3. **保存して同期** を押します
4. 右上の表示が **同期済み** になれば完了です。データ用リポジトリに `items.json` ができています

トークンは端末の中(このアプリの保存領域)にだけ保存され、画面にも再表示されません。
同期を使う端末(iPhone、PC のブラウザなど)ごとに、この設定を行ってください。

### うまくいかないとき

| 表示 | 確認すること |
|---|---|
| アクセストークンが無効か、期限切れです | トークンを貼り付け間違えていないか、期限が切れていないか |
| リポジトリが見つかりません | 持ち主・名前・ブランチのつづり。トークン作成時に、そのリポジトリを選んだか |
| 書き込み権限がありません | トークンの **Contents** が **Read and write** になっているか |
| 未送信 n | 通信できない状態です。通信できるようになると自動で送信されます |

### 端末を紛失したとき

1. 別の端末で GitHub にログインし、**Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** を開きます
2. 紛失した端末用のトークンを選び、**Delete** で削除します
3. これで、その端末からはデータ用リポジトリに触れなくなります

### 同期の仕組み(参考)

- 入力・編集・完了は、まず端末内に保存した時点で完了です。通信は裏で行われます
- 同期では、GitHub 上の `items.json` と端末内のデータを項目ごとに突き合わせ、`updated_at`(更新時刻)が新しいほうを採用します。片方にしかない項目はそのまま残ります
- 削除した項目は消さずに「削除済み」の印を付けて残します(同期の食い違いを防ぐため)
